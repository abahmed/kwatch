### Upgrading from 0.10.x

- **Installer (recommended):** run
  `/bin/bash -c "$(curl -fsSL https://kwatch.dev/kwatch.sh)"`. It
  finds a 0.10.x install and offers to recreate the Deployment; your
  configuration and Secrets are kept.
- **Helm:** `helm upgrade` works with your 0.10.x values file. The old
  `service` block is accepted and ignored.
- **`kubectl apply -f deploy/deploy.yaml`:** the Deployment selector
  changed (it now also matches `app.kubernetes.io/instance: kwatch`),
  and Kubernetes does not allow a selector to change. Delete the old
  Deployment first, then apply:

  ```sh
  kubectl delete deployment kwatch -n kwatch
  kubectl apply -f deploy/deploy.yaml
  ```

See [Upgrading to 1.0][upgrading] for every configuration change.
